# Generic Component Shims

MDX Preview provides built-in generic components that work across all frameworks. These components are available in **both Trusted Mode and Safe Mode** - no imports required!

> [!TIP]
> These components work without any imports in Trusted Mode. In Safe Mode, they're automatically transformed to semantic HTML.

---

## Callout / Alert / Admonition

All three names work identically - they're aliases for the same component:

<Callout type="note">
  This is a **Callout** component with `type="note"`.
</Callout>

<Alert type="tip">
  This is an **Alert** component. Same component, different name!
</Alert>

<Admonition type="warning">
  This is an **Admonition** component. Another alias for the same thing.
</Admonition>

---

## Callout Types

The Callout component supports 7 types, each with its own icon and color scheme:

### Note

<Callout type="note">
  **Note** - Use for general information and context. Blue color scheme with an info icon.
</Callout>

### Tip

<Callout type="tip">
  **Tip** - Use for helpful suggestions and best practices. Green color scheme with a lightbulb icon.
</Callout>

### Info

<Callout type="info">
  **Info** - Use for informational content. Blue color scheme, similar to note.
</Callout>

### Warning

<Callout type="warning">
  **Warning** - Use for potential issues and gotchas. Amber/orange color scheme with a warning icon.
</Callout>

### Danger

<Callout type="danger">
  **Danger** - Use for critical warnings about breaking changes or security. Red color scheme with an X icon.
</Callout>

### Caution

<Callout type="caution">
  **Caution** - Use for proceed-with-care situations. Amber/orange color scheme.
</Callout>

### Important

<Callout type="important">
  **Important** - Use for key information that shouldn't be missed. Purple color scheme with a check icon.
</Callout>

## Tabs / TabItem / Tab

Create tabbed content with the Tabs component:

<Tabs>
  <TabItem value="js" label="JavaScript">
    ```javascript
    function greet(name) {
      return `Hello, ${name}!`;
    }

    console.log(greet('World'));
    ```
  </TabItem>
  <TabItem value="ts" label="TypeScript">
    ```typescript
    function greet(name: string): string {
      return `Hello, ${name}!`;
    }

    console.log(greet('World'));
    ```
  </TabItem>
  <TabItem value="py" label="Python">
    ```python
    def greet(name):
        return f"Hello, {name}!"

    print(greet("World"))
    ```
  </TabItem>
</Tabs>

## CodeGroup

Group multiple code blocks into a tabbed interface. Labels are auto-extracted from language or title:

<CodeGroup>
```javascript
// JavaScript implementation
function add(a, b) {
  return a + b;
}
```
```typescript
// TypeScript implementation
function add(a: number, b: number): number {
  return a + b;
}
```
```python
# Python implementation
def add(a, b):
    return a + b
```
</CodeGroup>

</CodeGroup>

## Component API Reference

### Callout / Alert / Admonition Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `'note' \| 'tip' \| 'info' \| 'warning' \| 'danger' \| 'caution' \| 'important'` | `'note'` | Callout type/style |
| `title` | `string` | Type name | Custom title |
| `icon` | `ReactNode` | Type icon | Custom icon |
| `children` | `ReactNode` | required | Content |

**Type Aliases:**
- `success` -> `tip`
- `error` -> `danger`
- `warn` -> `warning`
- `hint` -> `tip`

### Collapsible / Accordion / Details Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | required | Summary/trigger text |
| `summary` | `string` | - | Alias for `title` |
| `defaultOpen` | `boolean` | `false` | Start expanded |
| `children` | `ReactNode` | required | Collapsible content |

### Tabs Props

| Prop | Type | Description |
|------|------|-------------|
| `defaultValue` | `string` | Initially selected tab value |
| `children` | `ReactNode` | TabItem components |

### TabItem / Tab Props

| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | Unique identifier |
| `label` | `string` | Display label |
| `children` | `ReactNode` | Tab content |

### CodeGroup Props

| Prop | Type | Description |
|------|------|-------------|
| `labels` | `string[]` | Explicit tab labels |
| `children` | `ReactNode` | Code block elements |

**Label Auto-Extraction Order:**
1. `title` prop on code block
2. `label` prop
3. `filename` prop
4. `language` / `lang` prop
5. Language from className (e.g., `language-javascript`)
