# Cards Grid

Cards display content in a responsive grid layout. The component uses a compound pattern with `Cards` and `Cards.Card`.

## Basic Usage

The simplest card grid with 3 columns (default):

<Cards>
  <Cards.Card title="Getting Started">
    Learn the basics of the framework.
  </Cards.Card>
  <Cards.Card title="API Reference">
    Complete API documentation.
  </Cards.Card>
  <Cards.Card title="Examples">
    Real-world usage examples.
  </Cards.Card>
</Cards>

```mdx
<Cards>
  <Cards.Card title="Getting Started">
    Description content
  </Cards.Card>
  <Cards.Card title="API Reference">
    Description content
  </Cards.Card>
  <Cards.Card title="Examples">
    Description content
  </Cards.Card>
</Cards>
```

## With Links

Cards can link to other pages or external URLs:

### Internal Links

<Cards num={2}>
  <Cards.Card
    icon="📝"
    title="Callouts Guide"
    href="./callouts"
  >
    Learn about callout components
  </Cards.Card>
  <Cards.Card
    icon="🗂️"
    title="Tabs Demo"
    href="./tabs-demo"
  >
    Explore tabbed content
  </Cards.Card>
</Cards>

### External Links

<Cards num={2}>
  <Cards.Card
    icon="🌐"
    title="Nextra Website"
    href="https://nextra.site"
    arrow
  >
    Official Nextra documentation
  </Cards.Card>
  <Cards.Card
    icon="📦"
    title="GitHub Repository"
    href="https://github.com/shuding/nextra"
    arrow
  >
    Source code and issues
  </Cards.Card>
</Cards>

<Callout type="info">
  External links (starting with `http://` or `https://`) automatically open in a new tab with `target="_blank"` and `rel="noopener noreferrer"`.
</Callout>

```mdx
<Cards.Card
  title="External Link"
  href="https://example.com"
  arrow
>
  Opens in new tab
</Cards.Card>
```

## Responsive Behavior

Cards automatically adjust to fewer columns on smaller screens:
- **Desktop**: Shows the specified `num` columns
- **Tablet**: Reduces to 2 columns
- **Mobile**: Stacks into a single column

<Callout>
  Resize your browser window to see the responsive behavior in action!
</Callout>

## API Reference

### Cards Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `num` | `number` | `3` | Number of grid columns |
| `children` | `ReactNode` | required | `Cards.Card` components |
| `className` | `string` | - | Additional container classes |

### Cards.Card Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | required | Card title |
| `icon` | `ReactNode` | - | Icon emoji or element |
| `href` | `string` | - | Link URL |
| `arrow` | `boolean` | `false` | Show arrow indicator |
| `children` | `ReactNode` | - | Card description content |
| `className` | `string` | - | Additional card classes |
