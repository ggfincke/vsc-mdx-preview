## What is Nextra?

[Nextra](https://nextra.site) is a Next.js-based documentation framework that provides:

- MDX-first authoring experience
- Built-in React components
- Automatic sidebar generation from `_meta.json`
- Theme support (docs and blog themes)

## Quick Start

<Steps>

### Open the Example

Open this `examples/nextra` folder in VS Code with the MDX Preview extension installed.

### Trust the Workspace

When prompted, trust the workspace to enable Trusted Mode features.

### Enable Scripts

Ensure `mdx-preview.preview.enableScripts` is set to `true` in your VS Code settings.

### Open an MDX File

Open any `.mdx` file in this folder and press `Cmd+K X` (Mac) or `Ctrl+K X` (Windows/Linux) to open the preview.

</Steps>
