# Tabs Component

Tabs organize content into switchable panels. Nextra's Tabs component uses a compound pattern with `Tabs` and `Tabs.Tab`.

## Basic Usage

The simplest form uses an array of strings for the `items` prop:

<Tabs items={['JavaScript', 'TypeScript', 'Python']}>
  <Tabs.Tab>
    ```js
    function greet(name) {
      return `Hello, ${name}!`;
    }

    console.log(greet('World'));
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```ts
    function greet(name: string): string {
      return `Hello, ${name}!`;
    }

    console.log(greet('World'));
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```python
    def greet(name):
        return f"Hello, {name}!"

    print(greet("World"))
    ```
  </Tabs.Tab>
</Tabs>

```mdx
<Tabs items={['JavaScript', 'TypeScript', 'Python']}>
  <Tabs.Tab>JavaScript content</Tabs.Tab>
  <Tabs.Tab>TypeScript content</Tabs.Tab>
  <Tabs.Tab>Python content</Tabs.Tab>
</Tabs>
```

## Default Selected Tab

Use `defaultIndex` to set which tab is selected initially:

<Tabs items={['Option A', 'Option B (Default)', 'Option C']} defaultIndex={1}>
  <Tabs.Tab>
    Content for Option A
  </Tabs.Tab>
  <Tabs.Tab>
    **This tab is selected by default** because `defaultIndex={1}` (0-indexed).
  </Tabs.Tab>
  <Tabs.Tab>
    Content for Option C
  </Tabs.Tab>
</Tabs>

```mdx
<Tabs items={['A', 'B (Default)', 'C']} defaultIndex={1}>
  ...
</Tabs>
```

## Rich Tab Content

Tabs can contain any MDX content:

<Tabs items={['Overview', 'Installation', 'Configuration']}>
  <Tabs.Tab>
    ## Project Overview

    This project provides a complete solution for building documentation sites.

    ### Features

    - MDX support
    - Automatic sidebar
    - Search functionality
    - Theme customization
  </Tabs.Tab>
  <Tabs.Tab>
    ## Installation Steps

    1. Create a new Next.js project:

       ```bash
       npx create-next-app my-docs
       ```

    2. Install dependencies:

       ```bash
       npm install nextra nextra-theme-docs
       ```

    3. Create the configuration file:

       ```js filename="next.config.mjs"
       import nextra from 'nextra'

       const withNextra = nextra({
         theme: 'nextra-theme-docs',
         themeConfig: './theme.config.tsx'
       })

       export default withNextra()
       ```
  </Tabs.Tab>
  <Tabs.Tab>
    ## Configuration Options

    | Option | Type | Default | Description |
    |--------|------|---------|-------------|
    | `theme` | `string` | required | Theme package name |
    | `themeConfig` | `string` | required | Theme config file path |
    | `defaultShowCopyCode` | `boolean` | `false` | Show copy button on code blocks |
    | `flexsearch` | `boolean` | `true` | Enable search |

    <Callout type="info">
      See the [configuration docs](https://nextra.site/docs/guide/configuration) for all options.
    </Callout>
  </Tabs.Tab>
</Tabs>

## API Reference

### Tabs Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `(string \| { label: string; disabled?: boolean })[]` | required | Array of tab labels |
| `defaultIndex` | `number` | `0` | Initial selected tab index |
| `selectedIndex` | `number` | - | Controlled mode: current selected index |
| `storageKey` | `string` | - | localStorage key for persistence |
| `onChange` | `(index: number) => void` | - | Callback when tab changes |
| `tabClassName` | `string \| ((index, selected) => string)` | - | Custom tab button classes |
| `className` | `string` | - | Additional container classes |

### Tabs.Tab Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | Tab panel content |
