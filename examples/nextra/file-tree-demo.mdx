# File Tree Component

The FileTree component displays directory structures with expandable folders, file icons, and optional highlights.

## Basic Structure

A simple file tree uses nested `<ul>` and `<li>` elements:

<FileTree>
  <ul>
    <li>pages/</li>
    <ul>
      <li>index.mdx</li>
      <li>about.mdx</li>
      <li>contact.mdx</li>
    </ul>
    <li>public/</li>
    <ul>
      <li>favicon.ico</li>
      <li>logo.svg</li>
    </ul>
    <li>package.json</li>
    <li>next.config.mjs</li>
  </ul>
</FileTree>

```mdx
<FileTree>
  <ul>
    <li>pages/</li>
    <ul>
      <li>index.mdx</li>
      <li>about.mdx</li>
    </ul>
    <li>package.json</li>
  </ul>
</FileTree>
```

<Callout type="info">
  Directories are identified by a trailing `/` in their name or by having a nested `<ul>` element.
</Callout>

## Comments

Add descriptive comments after file names:

<FileTree>
  <ul>
    <li><strong>src/</strong> source code</li>
    <ul>
      <li><strong>components/</strong> React components</li>
      <ul>
        <li>Button.tsx reusable button component</li>
        <li>Card.tsx card container</li>
        <li>Modal.tsx dialog component</li>
      </ul>
      <li>hooks/ custom React hooks</li>
      <ul>
        <li>useAuth.ts authentication hook</li>
        <li>useTheme.ts theme management</li>
      </ul>
      <li>utils/ helper functions</li>
    </ul>
    <li>public/ static assets</li>
    <li>package.json dependencies</li>
    <li>tsconfig.json TypeScript config</li>
  </ul>

```mdx
<li>Button.tsx reusable button component</li>
<li><strong>components/</strong> React components</li>
```

## Understanding `_meta.json`

Nextra uses `_meta.json` files to configure page titles and navigation. Here's an example structure:

<FileTree>
  <ul>
    <li>docs/</li>
    <ul>
      <li><strong>_meta.json</strong></li>
      <li>index.mdx</li>
      <li>components.mdx</li>
      <li>callouts.mdx</li>
      <li><strong>layouts/</strong></li>
      <ul>
        <li><strong>_meta.json</strong></li>
        <li>full-width.mdx</li>
        <li>raw-layout.mdx</li>
      </ul>
    </ul>
  </ul>
</FileTree>

The root `_meta.json` might look like:

```json
{
  "index": "Getting Started",
  "components": "Component Reference",
  "callouts": "Callouts Guide",
  "layouts": {
    "title": "Layout Examples",
    "type": "menu"
  }
}
```

<Callout>
  MDX Preview reads `_meta.json` files to extract page titles and layout settings. This is how it knows to display "Getting Started" as the page title even if the file is named `index.mdx`.
</Callout>

## Syntax Reference

<Steps>

### Mark Directories

End the name with `/` or include a nested `<ul>`:

```mdx
<li>folder/</li>
{/* or */}
<li>folder</li>
<ul>
  <li>child</li>
</ul>
```

### Highlight Items

Wrap in `<strong>` or `<b>`:

```mdx
<li><strong>important-file.tsx</strong></li>
```

### Add Comments

Add text after the file/folder name:

```mdx
<li>config.ts configuration file</li>
```

### Add Placeholders

Use `...` or `…`:

```mdx
<li>...</li>
```

</Steps>

## API Reference

### FileTree Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | Nested `<ul>/<li>` structure |
| `className` | `string` | - | Additional container classes |

### Markup Conventions

| Pattern | Meaning |
|---------|---------|
| `<li>name/</li>` | Directory |
| `<li>name</li><ul>...</ul>` | Directory with contents |
| `<li>name</li>` | File |
| `<li><strong>name</strong></li>` | Highlighted item |
| `<li>name comment</li>` | Item with comment |
| `<li>...</li>` or `<li>…</li>` | Placeholder |
