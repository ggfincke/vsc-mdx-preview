# Nextra Example

The example content lives in **[`index.mdx`](./index.mdx)** — open that file with `Cmd+K X` / `Ctrl+K X` to see the preview.

## What this demonstrates

- Framework auto-detection for Nextra (via `nextra` in `package.json`)
- The full Nextra component shim set: `Callout`, `Tabs`, `Cards`, `FileTree`, `Steps`, `Bleed`
- Frontmatter rendering and the `nextra/components` barrel import

## Why `index.mdx` instead of `README.mdx`?

Nextra-based docs sites conventionally treat `index.mdx` as the section entry. We keep that convention so the example mirrors what you'd see in a real Nextra workspace.
