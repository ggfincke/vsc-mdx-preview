# Next.js Image Component Examples

The `Image` component from `next/image` renders optimized images. In MDX Preview, images render as standard `<img>` elements without Next.js optimization (since we're not running a Next.js server).

## Image with Fill Mode

The `fill` prop makes the image fill its parent container. The parent must have `position: relative`:

<div style={{ position: 'relative', width: '100%', height: '200px', marginBottom: '1rem' }}>
  <Image
    src="./kitty.jpg"
    alt="Kitty using fill mode"
    fill
  />
</div>

With `fill`, the image uses `position: absolute` and `objectFit: cover` by default.

## Priority Loading

Use `priority` for above-the-fold images that should load immediately:

<Image
  src="./kitty.jpg"
  alt="Priority loading kitty"
  width={300}
  height={225}
  priority
/>

Priority images use `loading="eager"` instead of the default `loading="lazy"`.

## Combining Link and Image

Wrap Image in Link to create linked images:

<Link href="/products/featured">
  <Image
    src="./kitty.jpg"
    alt="Linked kitty image"
    width={400}
    height={300}
    style={{ cursor: 'pointer' }}
  />
</Link>

## Image Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string \| { src: string }` | required | Image source URL |
| `alt` | `string` | required | Alt text for accessibility |
| `width` | `number \| string` | - | Image width (required unless `fill`) |
| `height` | `number \| string` | - | Image height (required unless `fill`) |
| `fill` | `boolean` | `false` | Fill parent container |
| `priority` | `boolean` | `false` | Load immediately (eager) |
| `placeholder` | `'blur' \| 'empty'` | `'empty'` | Placeholder type |
| `blurDataURL` | `string` | - | Base64 blur placeholder |
| `className` | `string` | - | Additional CSS classes |
| `style` | `CSSProperties` | - | Inline styles |

**Ignored Props (Next.js-specific):**
- `quality`, `loader`, `unoptimized`, `sizes`

## Image Shim Behavior

The MDX Preview shim provides simplified functionality:

- Renders as a standard `<img>` element
- No image optimization (uses original image)
- `fill` mode uses CSS for positioning
- `priority` sets `loading="eager"` instead of `loading="lazy"`
- Blur placeholder uses CSS `backgroundImage`

This means previews may look slightly different from a running Next.js app, but the structure and content will be correct.
