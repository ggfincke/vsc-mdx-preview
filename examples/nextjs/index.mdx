# Next.js MDX Preview Examples

This example demonstrates MDX Preview's support for Next.js components (`next/image` and `next/link`).

## Framework Detection

When viewing this file in MDX Preview, the status bar should display:

**▲ Next.js**

This confirms that the Next.js framework has been detected based on the `next` and `@mdx-js/react` dependencies in [package.json](./package.json).

---

## Image Component

The `Image` component from `next/image` renders images. In MDX Preview, images render as standard `<img>` elements without Next.js optimization.

### Basic Image

<Image
  src="./kitty.jpg"
  alt="Cute kitty cat"
  width={640}
  height={480}
/>

### Fill Mode

The `fill` prop makes the image fill its parent container:

<div style={{ position: 'relative', width: '100%', height: '200px', marginBottom: '1rem' }}>
  <Image
    src="./kitty.jpg"
    alt="Kitty using fill mode"
    fill
  />
</div>

## Props Reference

### Image Props

| Prop | Type | Description |
|------|------|-------------|
| `src` | `string` | Image source URL (required) |
| `alt` | `string` | Alt text for accessibility (required) |
| `width` | `number` | Image width (required unless `fill`) |
| `height` | `number` | Image height (required unless `fill`) |
| `fill` | `boolean` | Fill parent container |
| `priority` | `boolean` | Load immediately (eager) |
| `style` | `CSSProperties` | Inline styles |

### Link Props

| Prop | Type | Description |
|------|------|-------------|
| `href` | `string` | Destination URL (required) |
| `children` | `ReactNode` | Link content (required) |
| `style` | `CSSProperties` | Inline styles |
