# Next.js MDX Preview Examples

This example demonstrates MDX Preview's support for Next.js components (`next/image` and `next/link`).

## Available Components

Explore the different Next.js components with these examples:

- [Image Component](./image-component.mdx) - `next/image` examples with kitty photos
- [Link Component](./link-component.mdx) - `next/link` examples with internal and external navigation
- [Routing Patterns](./routing.mdx) - Advanced navigation patterns and object-style hrefs

## Framework Detection

When viewing this file in MDX Preview, the status bar should display:

**▲ Next.js**

This confirms that the Next.js framework has been detected based on the `next` and `@mdx-js/react` dependencies in [package.json](./package.json).

## External Links

External links can be opened with **Ctrl/Cmd+Click** (e.g., links to https://google.com or https://github.com). This opens the link in your default browser.
