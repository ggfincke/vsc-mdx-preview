# Next.js Example

The example content lives in **[`index.mdx`](./index.mdx)** — open that file with `Cmd+K X` / `Ctrl+K X` to see the preview.

## What this demonstrates

- Framework auto-detection for Next.js (via `next` + `@mdx-js/react` in `package.json`)
- The `next/image` and `next/link` shims provided by MDX Preview
- Local image rendering through the shim (`./kitty.jpg`)

## Why `index.mdx` instead of `README.mdx`?

Next.js MDX projects conventionally treat `index.mdx` as the page entry. We keep that convention here so the example mirrors what you'd see in a real Next.js app.
