# Routing and Navigation Patterns

Advanced routing patterns using the `Link` component with object-style hrefs and query parameters.

> [!TIP]
> **Navigation:** <Link href="./index.mdx">← Back to Home</Link> | <Link href="./image-component.mdx">← Image Examples</Link> | <Link href="./link-component.mdx">← Link Examples</Link>

---

## Object-Style Href

Instead of passing a string to `href`, you can use an object with `pathname`, `query`, and `hash` properties:

<Link href={{ pathname: './image-component.mdx', hash: 'basic-image' }}>
  Jump to Basic Image Example
</Link>

This is equivalent to: `./image-component.mdx#basic-image`

## Query Parameters {#query-parameters}

In a real Next.js app, query parameters would be passed to the page component via router. In the preview, the query string is generated but not functional:

<div style={{ display: 'flex', flexDirection: 'column', gap: '0.5rem', marginBottom: '2rem' }}>
  <Link href={{ pathname: './index.mdx', query: { tab: 'overview' } }}>
    Home with tab=overview
  </Link>

  <Link href={{ pathname: './index.mdx', query: { tab: 'docs', section: 'api' } }}>
    Home with multiple query params
  </Link>

  <Link href={{ pathname: 'https://google.com', query: { q: 'mdx preview' } }}>
    Google search for "mdx preview"
  </Link>
</div>

**Generated URLs:**
- `./index.mdx?tab=overview`
- `./index.mdx?tab=docs&section=api`
- `https://google.com?q=mdx+preview`

## Pathname, Query, and Hash Combined

Combine all three parts for precise navigation:

<Link href={{
  pathname: './link-component.mdx',
  query: { ref: 'homepage' },
  hash: 'styled-links'
}}>
  View Styled Links (with referrer tracking)
</Link>

This generates: `./link-component.mdx?ref=homepage#styled-links`

## Dynamic Routes (Conceptual)

In Next.js, you can use dynamic route segments. In the preview, these render as literal strings:

<div style={{ display: 'flex', flexDirection: 'column', gap: '0.5rem', marginBottom: '2rem' }}>
  <Link href={{
    pathname: '/products/[id]',
    query: { id: '123' }
  }}>
    Product #123
  </Link>

  <Link href={{
    pathname: '/blog/[year]/[month]/[slug]',
    query: { year: '2025', month: '01', slug: 'hello-world' }
  }}>
    Blog Post: Hello World (Jan 2025)
  </Link>
</div>

**Generated URLs:**
- `/products/[id]?id=123` (in real Next.js, this would resolve to `/products/123`)
- `/blog/[year]/[month]/[slug]?year=2025&month=01&slug=hello-world`

## UrlObject Interface Reference

```typescript
interface UrlObject {
  pathname?: string;  // Path component (e.g., '/docs' or './page.mdx')
  query?: Record<string, string>;  // Query parameters as key-value pairs
  hash?: string;  // Fragment/anchor (with or without leading #)
}
```

### Examples

| Object | Generated URL |
|--------|---------------|
| `{ pathname: './index.mdx' }` | `./index.mdx` |
| `{ pathname: './index.mdx', hash: 'section' }` | `./index.mdx#section` |
| `{ pathname: './index.mdx', query: { tab: 'docs' } }` | `./index.mdx?tab=docs` |
| `{ pathname: './index.mdx', query: { a: '1', b: '2' }, hash: 'top' }` | `./index.mdx?a=1&b=2#top` |

## How It Works in MDX Preview

### String Href
Simple string hrefs work as-is:
```jsx
<Link href="./page.mdx">Link Text</Link>
```

### Object Href
Object hrefs are converted to strings:
```jsx
<Link href={{ pathname: './page.mdx', query: { id: '123' }, hash: 'section' }}>
  Link Text
</Link>
```

The Link component's `resolveHref` function:
1. Extracts `pathname` (defaults to empty string)
2. Serializes `query` object to URLSearchParams
3. Appends `hash` (with `#` prefix)
4. Returns combined string
