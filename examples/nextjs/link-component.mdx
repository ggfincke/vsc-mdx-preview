## External Links

External links can be opened with **Ctrl/Cmd+Click** and include proper security attributes (`target="_blank"` and `rel="noopener noreferrer"`):

<div style={{ display: 'flex', flexDirection: 'column', gap: '0.5rem', marginBottom: '2rem' }}>
  <Link href="https://google.com">Google Search</Link>
  <Link href="https://github.com/ggfincke/vsc-mdx-preview">VSC MDX Preview Repository</Link>
  <Link href="https://nextjs.org/docs">Next.js Documentation</Link>
</div>

**How it works:**
- External links are auto-detected by checking if the URL starts with `http://` or `https://`
- Use **Ctrl+Click** (Windows/Linux) or **Cmd+Click** (Mac) to open in your browser
- Regular clicks are ignored (for visual preview only)

## Link Props Reference

| Prop | Type | Description |
|------|------|-------------|
| `href` | `string \| UrlObject` | **Required.** Destination URL |
| `children` | `ReactNode` | **Required.** Link content |
| `className` | `string` | Additional CSS classes |
| `style` | `CSSProperties` | Inline styles |

**UrlObject Structure:**
```typescript
interface UrlObject {
  pathname?: string;
  query?: Record<string, string>;
  hash?: string;
}
```

**Ignored Props (Next.js-specific):**
- `as`, `replace`, `scroll`, `shallow`, `passHref`, `prefetch`, `locale`, `legacyBehavior`

## Link Shim Behavior

The MDX Preview shim provides visual rendering with limited interactivity:

- Renders as a standard `<a>` element with proper attributes
- **External links** (`http://` or `https://`): Can be opened with Ctrl/Cmd+Click
- **Internal links**: Display-only (navigation will be added in a future update)
- Query objects are serialized to query strings
- Structure and visual presentation match what you'd see in a running Next.js app

This provides accurate visual preview while allowing you to quickly open external documentation and resources.
