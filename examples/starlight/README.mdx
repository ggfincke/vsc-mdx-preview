# Starlight Component Shims

MDX Preview provides built-in shims for Astro Starlight's component library. These work without installing Starlight - the extension provides compatible implementations.

> [!TIP]
> **Trusted Mode Required**: These components require a trusted workspace with `mdx-preview.preview.enableScripts` enabled.

## Steps Component

Display numbered step-by-step instructions.

<Steps>

1. **Install Starlight**

   Add Starlight to your Astro project:

   ```bash
   npx astro add starlight
   ```

2. **Configure Your Project**

   Edit your `astro.config.mjs`:

   ```javascript
   import starlight from '@astrojs/starlight';

   export default defineConfig({
     integrations: [starlight({ title: 'My Docs' })],
   });
   ```

3. **Add Your Content**

   Create MDX files in `src/content/docs/`:

   <FileTree>
   - src/
     - content/
       - docs/
         - index.mdx
         - getting-started.mdx
         - guides/
           - first-guide.mdx
   </FileTree>

4. **Start Developing**

   Run the development server:

   ```bash
   npm run dev
   ```

   Open `http://localhost:4321` to see your docs!

</Steps>

## Import Patterns

MDX Preview supports these import patterns for Starlight components:

```javascript
// Barrel import (recommended)
import {
  Card,
  CardGrid,
  LinkCard,
  Badge,
  Aside,
  Tabs,
  TabItem,
  Steps,
  FileTree,
  Code
} from '@astrojs/starlight/components';

// Individual component imports
import { Card } from '@astrojs/starlight/components/Card';
import { Code } from '@astrojs/starlight/components/Code';

// Direct shim imports (fallback)
import { Card } from '@mdx-preview/shims/starlight/Card';
```

## Component API Reference

### Card Props

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | **Required.** Card title |
| `icon` | `string` | Optional icon name |
| `children` | `ReactNode` | Card content |

### CardGrid Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | Card components |
| `stagger` | `boolean` | `false` | Enable stagger animation |

### LinkCard Props

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | **Required.** Card title |
| `description` | `string` | Optional description |
| `href` | `string` | **Required.** Link URL |

### Badge Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `ReactNode` | required | Badge text |
| `variant` | `'note' \| 'tip' \| 'caution' \| 'danger' \| 'success' \| 'default'` | `'default'` | Color variant |
| `size` | `'small' \| 'medium' \| 'large'` | `'small'` | Badge size |

### Aside Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | Aside content |
| `type` | `'note' \| 'tip' \| 'caution' \| 'danger'` | `'note'` | Aside type |
| `title` | `string` | Type-based | Custom title |

### Tabs Props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `ReactNode` | TabItem components |

### TabItem Props

| Prop | Type | Description |
|------|------|-------------|
| `label` | `string` | Tab label |
| `children` | `ReactNode` | Tab content |

### Steps Props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `ReactNode` | Ordered list with step content |

### FileTree Props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `ReactNode` | Nested list structure |

### Code Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `code` | `string` | required | Code content |
| `lang` | `string` | - | Language for highlighting |
| `title` | `string` | - | Title bar text |
| `frame` | `'code' \| 'terminal' \| 'none' \| 'auto'` | `'auto'` | Frame style |
