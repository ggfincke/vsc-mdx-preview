# Docusaurus Component Shims

MDX Preview provides built-in shims for Docusaurus's `@theme/*` components. These work without installing Docusaurus - the extension provides compatible implementations.

> [!TIP]
> **Trusted Mode Required**: These components require a trusted workspace with `mdx-preview.preview.enableScripts` enabled.

---

<CodeBlock language="typescript" title="src/utils/math.ts">

  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

export function isPrime(n: number): boolean {
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}`}
</CodeBlock>

### CodeBlock with Line Numbers

<CodeBlock language="python" showLineNumbers>
{`def quicksort(arr):
    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    return quicksort(left) + middle + quicksort(right)

# Example usage

sorted_numbers = quicksort(numbers)

## Import Patterns

MDX Preview supports these import patterns for Docusaurus components:

```javascript
// Standard @theme imports
import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';
import CodeBlock from '@theme/CodeBlock';
import Details from '@theme/Details';

// Direct shim imports (fallback)
import { Tabs, TabItem } from '@mdx-preview/shims/docusaurus/Tabs';
import { CodeBlock } from '@mdx-preview/shims/docusaurus/CodeBlock';
import { Details } from '@mdx-preview/shims/docusaurus/Details';
```

## Component API Reference

### Tabs Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | TabItem components |
| `defaultValue` | `string` | first tab | Initially selected tab value |
| `values` | `TabDefinition[]` | - | Programmatic tab definitions |
| `groupId` | `string` | - | Sync tabs with same groupId |
| `className` | `string` | - | Additional CSS classes |

### TabItem Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | Tab content |
| `value` | `string` | required | Unique identifier |
| `label` | `string` | - | Display label |
| `default` | `boolean` | false | Mark as default tab |
| `attributes` | `object` | - | Additional HTML attributes |

### CodeBlock Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `string` | required | Code content |
| `language` | `string` | - | Syntax highlighting language |
| `title` | `string` | - | Title bar text |
| `showLineNumbers` | `boolean` | false | Show line numbers |
| `metastring` | `string` | - | Additional metadata |
| `className` | `string` | - | Additional CSS classes |

### Details Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | required | Collapsible content |
| `summary` | `ReactNode` | 'Details' | Summary/trigger text |
| `open` | `boolean` | false | Start expanded |
| `className` | `string` | - | Additional CSS classes |
