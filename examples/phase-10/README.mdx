# Phase 10 — UX Polish

This file demonstrates the three features introduced in Phase 10.

---

## 10.1 — Crossnote-Inspired Formatting

Preview styling adopts crossnote-inspired formatting with Material Design
elevation, graduated heading scales, and refined typography.

### Typography Changes

The base font-size is now **16px** (up from 14px) with a **1.6** line-height
for improved readability. Headings follow a graduated scale:

# H1 — 2.25em
## H2 — 1.75em
### H3 — 1.5em
#### H4 — 1.25em
##### H5 — 1em
###### H6 — 1em (muted color)

H1 and H2 no longer have `border-bottom` lines — the heading scale alone
provides enough visual hierarchy.

### Blockquotes

Blockquotes now have a background color for better visual distinction:

> "The best way to predict the future is to invent it."
>
> — Alan Kay

HRs are thicker (4px) with more breathing room (32px margin):

### Callouts — Material Design elevation

Callouts now feature Material Design box-shadow, `.4rem` left border,
`.2rem` border-radius, and a colored title bar with 10% opacity background.

<Callout type="note">

  that extends edge-to-edge.
</Callout>

<Callout type="tip">
  Hover over the callout — transitions are scoped to `background-color` and
  `border-color` only, so resizing the window never causes a flash.
</Callout>

<Callout type="warning">
  All callout types got the Material Design treatment. Try switching VS Code
  between light and dark mode — contrast is always correct.

<Callout type="danger">

## 10.2 — Error "Open in Editor"

Trigger a runtime error and navigable stack frames become **clickable**. Hover
over a user-code frame — it gets a pointer cursor and a highlight. Click it and
VS Code jumps to that exact file and line.

To test this, temporarily introduce an error in a trusted MDX file:

```mdx
import { doesNotExist } from './missing-module';

# My Doc

<doesNotExist />
```

User-code frames (your workspace files) are clickable. Node internals and
bundler frames are not — they render as plain text.

**Keyboard accessible**: Tab to a navigable frame and press Enter or Space.

## 10.3 — Explorer Context Menu

Right-click any `.mdx` or `.md` file in the **Explorer** panel — you'll see
**"Open MDX Preview"** in the context menu. This opens the preview for that
file even if it isn't the active editor.

The same entry appears when right-clicking an editor tab.

> [!NOTE]
> The existing keyboard shortcut (`Cmd+K X` / `Ctrl+K X`) still works
> unchanged — it opens a preview for the currently active editor.
